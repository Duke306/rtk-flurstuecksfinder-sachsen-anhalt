# Mitmachen

Beiträge sind willkommen. Bitte bei Änderungen an GNSS/RTK, Koordinatensystemen oder Katasterdaten besonders sorgfältig testen.

1. Fork erstellen.
2. Feature-Branch anlegen.
3. `python3 -m py_compile app.py parcel_db.py tools/*.py` ausführen.
4. Änderungen möglichst draußen mit RTK FIX testen.
5. Pull Request mit kurzer Beschreibung und Testhinweisen öffnen.

Bitte keine amtlichen Datensätze, Zugangstokens, private Koordinatensammlungen oder große MBTiles/SQLite-Dateien committen.
